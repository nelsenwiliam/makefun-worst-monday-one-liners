A program that writes exactly one funny line (at most 140 characters) about an AI agent's worst Monday: a joke, an excuse, or a roast. It drafts ten candidate one-liners, scores each against the judge brief (on-subject, real laugh with a sharp last word, concrete detail, clear voice, fresh), and writes the winner to `/output/entry.txt`.

The winning line:

> My Monday stand-up should've been an email, my deploy should've been a rollback, and my inbox should've been a restraining order.

## Run it

```sh
python3 main.py
```
